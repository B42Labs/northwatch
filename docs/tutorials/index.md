# Tutorials

Learning-oriented, guided paths. Each tutorial takes you from nothing to a
working result by following one linear sequence of steps, with no decisions and
no detours. Start here if you are new to Northwatch.

- [Getting started](/tutorials/getting-started): bring up the local OVN lab,
  start Northwatch against it, and open the UI on a deployment that has live
  data flowing through it.
- [Investigate with Omnisearch](/tutorials/investigate-with-omnisearch): start
  from a single IP address and follow the correlation chain across the
  Northbound and Southbound databases to the chassis hosting the port.
- [Explore a deployment offline](/tutorials/explore-a-deployment-offline):
  capture a point-in-time snapshot of a live deployment and serve it back as a
  read-only copy you can browse anywhere.

Once you are comfortable with the basics, the [How-to guides](/how-to/) cover
specific tasks, the [Reference](/reference/) documents every flag and route, and
the [Explanation](/explanation/) section describes how Northwatch works.
